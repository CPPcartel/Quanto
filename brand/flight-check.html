What a player walks through

Each stage can only happen after the one above it. Two of them have never been executed by a human being.

1
Arrive and sign in Live Untested by you

Email or wallet, through Privy. The server refuses an unauthenticated join outright, so there is no guest path in and no way to skip this. Verified in production against forged tokens, unsigned JWTs and empty tokens — all refused. A real token has never been accepted, because that needs your browser.

onAuthREQUIRE_AUTH=true401 on failure
2
Claim a username Live Untested by you

A gate, not a setting. Availability is checked as they type, names are unique case-insensitively, and staff-looking names plus the Trader#### shape are reserved. Renaming afterwards carries a one-week cooldown, shown as a date rather than hidden behind a rejection.

claimNamelower(name)unique index
3
Walk the city Live

38 towers whose heights are live Chainlink reads, four districts, chat, crews, direct messages, storms and shifts. Movement is server authoritative with client prediction, so the game feels instant and the server still decides.

applyInput60 Hz sim · 20 Hz replication
4
Earn and trade Live

Shifts pay, floors yield, and floors trade between players. Every unit of currency comes from an append-only ledger row, so SUM(ledger) = balance must hold for every player and is published at /audit. Trades settle in one transaction with canonical lock ordering and a deadlock retry.

/auditappend-only40P01 retried
5
Customise the profile Live

Name, colour and appearance. Holder-only traits are reserved for Quanto Residents holders and enforced server-side — a modified client asking for the halo gets the default in that slot. A chosen look survives reconnects and beats the NFT traits until cleared.

setAvatarsanitiseTraitsserver enforced
6
The season closes Live

Monday 00:00 UTC. Standings are frozen at the boundary and written once — never rewritten, even by a retry. Survives the boundary passing while the server is down, which is precisely the hour a deploy lands on. The signup grant does not count as earnings.

season_resultsclosed_atwrite-once
7
Review and pay Live Needs legal sign-off

The operator reviews the top entrants — account age, sessions, linked wallets, earnings by kind, score per hour — then records the payout. Recording is idempotent: asking twice returns the transaction already on file rather than overwriting it. Payment status and transaction hash are public, so anyone can check the winner was paid.

/admin/season/:id/reviewpaid_at IS NULL
8
Hold an NFT, enter the Vault Inert

Built and switched off. The collection is not deployed, so COLLECTION_ADDRESS is unset, everyone resolves to tier none and the Vault admits nobody. Nothing is broken — the gate simply has nothing to check. Setting one address turns on tiers, traits, chartered crews and penthouse territory.

What is stopping you

In order. The first two are the only real blockers, and both are things only you can do.

01
Add your domain to Privy

The allowed-domains list is empty. Localhost works by default; a production origin generally does not. If Privy refuses the origin, the login modal never initialises and every visitor sees a dead sign-in button while the server reports itself perfectly healthy. This is the most likely thing to break for your first visitor.

02
Sign in yourself, once, end to end

Sign in, claim a name, buy a floor, reload, confirm it is still there. Nothing that has been verified covers this: the door is proven to reject bad tokens, and has never been seen accepting a good one. The username gate has also only ever run with authentication disabled.

03
Rotate the two credentials

The Supabase password and the Privy app secret were both pasted into chat and should be treated as exposed. Rotate them and update Railway. The database is empty, so today this costs nothing — that stops being true with your first real player.

04
Decide the domain

The X header and the launch article both say quanto.fun, which you do not own. Either buy it — in which case Railway's allowed origin has to change too, or CORS will block the real site — or the copy gets swapped to the Vercel URL.

The one decision still open

Not a task. A judgement, and it has a deadline of your first paid season.

A6
Does paying on this metric create derivative exposure?

Season rank is measured in $BLOCK earned, and part of that comes from floor yield, which scales with a real asset's volatility. Pay a prize with cash value on that score and the payout partly tracks how a real security performed. That is the same exposure betting on price direction was excluded to avoid, reached by a longer route. The code keeps it a one-line decision: drop floor_yield from MARKET_LINKED_EARNING_KINDS and the metric stops tracking the market. Ask counsel this question explicitly — it is the one that gets skipped.
